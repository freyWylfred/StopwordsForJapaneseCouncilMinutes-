#  Stopwords For Japanese Council Minutes

日本の地方議会・国会等の議事録を自然言語処理する際に利用することを目的とした、  
**議会議事録ドメイン特化型の日本語ストップワード辞書**です。

議員発言の分析、ベクトル化、検索、クラスタリング、トピック分析などにおいて、  
議事録内で頻出する一方で、発言内容の特徴を捉えるうえでは寄与しにくい語を除外するために利用できます。

---

## 対象

本ストップワード辞書は、主に以下の用途を想定しています。

- 地方議会会議録
- 国会会議録
- 委員会議事録
- 議員発言分析
- TF-IDFによる特徴量抽出
- 文書ベクトル化
- クラスタリング
- トピック分析
- 類似発言検索
- RAG / ベクトル検索の前処理

---

## Stop Word の選定基準

以下のような語をストップワード候補として扱っています。

1. 議事進行上、頻繁に出現する語
2. 政策内容や発言テーマとの関連性が比較的低い語
3. 多くの議員が共通して使用する定型表現
4. 発言内容の特徴量として寄与しにくい敬語・定型句
5. 議会議事録の構造上、頻出しやすい一般語
6. 分析対象において識別力が低いと判断した語

> [!NOTE]
> ストップワードとして適切な語は、分析目的・対象自治体・対象期間・利用する自然言語処理手法によって異なります。  
> 本辞書は汎用的な初期値として利用し、必要に応じて追加・削除することを推奨します。

## 使用例

### Python

```python
text_tokens = [
    "議員",
    "質問",
    "子育て",
    "支援",
    "について",
    "考える"
]

filtered_tokens = [
    token
    for token in text_tokens
    if token not in custom_stopwords
]

print(filtered_tokens)
```

出力例:

```text
['子育て', '支援', 'について']
```

実際には、MeCab、SudachiPy、Janome、GiNZA などの形態素解析器と組み合わせて利用することを想定しています。

## 利用上の注意

### 1. 分析目的によって削除しない方がよい語があります

例えば以下の語は、分析内容によっては重要な情報となります。

- 質問
- 答弁
- 意見
- 方針
- 検討
- 対応
- 必要
- 事業
- 地域

「政策テーマそのものを分析する」のか、  
「議員の発言スタイルを分析する」のか、  
「質問と答弁を分類する」のかによって、適切なストップワードは異なります。

---

### 2. 固有地名について

現在のリストには以下のような語が含まれています。

- 世田谷区
- 世田谷
- せたがや

特定自治体の議事録だけを分析する場合、自治体名はほぼ全ての文書に登場するため、  
特徴量としての識別力が低くなる場合があります。

一方で、複数自治体を横断して比較する場合には重要な情報になる可能性があります。

---

### 3. 数値について

現在のリストには以下の数値も含まれています。

```text
10
11
26
29
100
```

数値をストップワードとして扱う場合は、個別値を登録するよりも、  
前処理段階で数値全般を正規表現等で処理する方法も推奨されます。

例:

```python
import re

token = re.sub(r"^\d+$", "", token)
```

## 推奨される利用方法

本辞書をそのまま固定的に利用するのではなく、以下のような流れで調整することを推奨します。

```text
議事録収集
    ↓
形態素解析
    ↓
単語頻度 / Document Frequency の確認
    ↓
既存ストップワード適用
    ↓
高頻度・低識別力語を追加
    ↓
分析結果を確認
    ↓
ストップワード辞書を再調整
```

議会・自治体・分析目的ごとに独自のストップワードを追加することで、  
より精度の高い文書分析につながる可能性があります。
